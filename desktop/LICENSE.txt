2. REQUIRED PERMISSIONS & INSTALLATION OPTIONS
--------------------------------------------------------------------------------
Ziphay AI is designed to run with minimal, non-invasive system privileges:
• User-Level Installation: Installs directly to your user profile directory
  (%LOCALAPPDATA%\Programs\Ziphay AI). Administrator rights are NOT required.
• Windows File Explorer Context Menu: Optionally registers cascading menu items
  under the Current User registry (HKCU\Software\Classes) for image and media files.
  No system-wide machine keys (HKLM) are modified without user intent.
• Disk Read/Write: The application only accesses files explicitly opened, dragged,
  or selected through the Windows File Explorer context menu.
• No Background Telemetry / Zero Daemons: Ziphay AI does not install persistent
  background services, monitoring daemons, or autostart hooks.

--------------------------------------------------------------------------------
3. PRIVACY POLICY & ON-DEVICE PROCESSING GUARANTEE
--------------------------------------------------------------------------------
Ziphay AI adheres strictly to the "Browser-First and Desktop Zero-Storage Principle":
• 100% Local Processing: All image compression, resizing, format conversion,
  denoising, and AI upscaling operations execute entirely on your local computer's
  CPU, GPU, and memory.
• Zero Cloud Uploads: Media files selected for processing are never uploaded,
  transferred, copied, or stored on remote cloud servers.
• Safe Non-Destructive Saving: Your original media files are never overwritten
  by default; output files are saved safely with an identifying suffix (e.g., _ziphay).
